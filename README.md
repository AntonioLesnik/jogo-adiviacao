# Jogo de Adivinhação — Aula 15

Projeto da disciplina de Mobile sobre:

- Navegação entre Activities com `Intent`
- Transferência de dados com `putExtra()`
- Recebimento com `getStringExtra()` e `getIntExtra()`
- Uso de `finish()`
- Jogo de adivinhação com número aleatório
- Contagem de tentativas
- Dicas de "Quente" e "Frio"
- Botão para jogar novamente

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta no Android Studio.
3. Aguarde o Gradle sincronizar.
4. Execute em um emulador ou celular Android.

## Tecnologias

- Kotlin
- Android
- XML
- AndroidX AppCompat
